# Pandora: The Forbidden Gift — v1.0.0

Pandora is an original first-person 3D puzzle set in a Greek-inspired temple. Open the forbidden gift, survive the tremors, and find a safe way across the chasm.

- Solve a complete, self-contained temple puzzle with a short optional prologue.
- Discover an original Blender-built chest and ceremonial portal.
- Reach a cinematic ending with Play Again and Main Menu options.
- Press Esc to return directly to the main menu from the temple or the ending.

The Windows x86_64 edition is a standalone build. Extract the attached ZIP and run `Pandora.exe`. The archive includes the Godot and bundled third-party notices.
