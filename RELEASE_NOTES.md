# Pandora: The Forbidden Gift — v1.0.1

This update refines fullscreen controls and makes the temple puzzle easier to read.

- Press F11 once to enter fullscreen from a maximized menu. Toggling fullscreen in Settings keeps keyboard focus where it was.
- Get clearer instructions when the box is out of reach, the slab is falling, or a failed crossing resets the room.
- Invalid saved settings use safe defaults. An incomplete temple scene returns to the main menu.

Extract the Windows x64 ZIP to a new folder and run `Pandora.exe`. The archive includes the Godot and bundled third-party notices. Use the attached SHA-256 file to verify the download.

See the [README](https://github.com/givi588/pandora-the-forbidden-gift/blob/v1.0.1/README.md) for controls and build instructions and the [asset rights notice](https://github.com/givi588/pandora-the-forbidden-gift/blob/v1.0.1/ASSET_RIGHTS.md) for artwork and audio rights. The [v1.0.0 release](https://github.com/givi588/pandora-the-forbidden-gift/releases/tag/v1.0.0) remains available.
